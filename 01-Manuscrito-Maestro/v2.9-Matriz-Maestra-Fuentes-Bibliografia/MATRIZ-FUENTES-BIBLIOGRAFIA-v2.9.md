## 1. Propósito

La v2.9 establece el estándar común para registrar, evaluar y normalizar las fuentes de los 20 expedientes. No sustituye las bibliografías individuales ni inventa referencias faltantes. Su función es preparar una bibliografía maestra trazable y detectar qué expedientes requieren R1/R2 antes de pasar a Canva.

---

# 2. Jerarquía oficial de fuentes

| Clase | Nombre | Uso editorial |
|---|---|---|
| **S1** | Fuente primaria | Evidencia o registro original: archivo, documento, periódico contemporáneo, entrevista/testimonio original, registro primario. |
| **S2** | Fuente académica | Investigación revisada, libro académico, universidad, archivo académico o estudio especializado. |
| **S3** | Fuente institucional | Museo, gobierno, biblioteca, parque, organismo histórico o institución cultural. |
| **S4** | Fuente secundaria especializada | Investigador, sociedad folklórica, obra especializada o divulgación experta. |
| **S5** | Fuente popular | Prensa secundaria, blogs, turismo, Wikipedia, redes o entretenimiento. |

### Regla de interpretación

La clase de fuente **no equivale a veracidad automática**. Una fuente S1 puede contener un testimonio falso; una S5 puede apuntar hacia una fuente primaria válida. La clasificación describe el **tipo y proximidad de la fuente al hecho**, no su conclusión.

---

# 3. Reglas de independencia

1. Cinco páginas que copian el mismo artículo cuentan como una cadena documental, no como cinco fuentes independientes.
2. Una fuente secundaria puede utilizarse para localizar una primaria, pero la primaria debe citarse cuando haya sido consultada.
3. Una afirmación atribuida a un investigador debe presentarse como afirmación del investigador.
4. Una fotografía o video debe tener procedencia separada de la interpretación que se hace de él.
5. La ausencia de fuente no se completa con memoria del modelo ni con una referencia plausible inventada.
6. Si no se puede verificar una referencia, se marca **PENDIENTE DE VERIFICACIÓN**.
7. Las fuentes populares pueden documentar la circulación de una leyenda, pero no elevar por sí mismas el nivel IIIC.

---

# 4. Campos obligatorios de la matriz maestra

Cada referencia definitiva deberá poder registrarse con:

- ID de fuente;
- código del expediente;
- autor/organización;
- título;
- fecha;
- tipo de fuente S1–S5;
- publicación/archivo/institución;
- URL o identificador bibliográfico cuando exista;
- fecha de consulta para recursos web;
- qué afirmación respalda;
- si es fuente primaria o secundaria;
- independencia respecto de otras fuentes;
- estado de verificación.

---

# 5. ID de fuentes

La bibliografía maestra utilizará identificadores estables:

`SRC-001`, `SRC-002`, `SRC-003` …

Una misma fuente utilizada por varios expedientes conserva **un único ID** y se vincula a todos los códigos correspondientes.

# 10. Reglas bibliográficas para Canva

Antes de aprobar un expediente para diseño:

- [ ] Todas las fuentes citadas en el texto aparecen en bibliografía.
- [ ] Todas las entradas bibliográficas son realmente utilizadas.
- [ ] No existen referencias duplicadas bajo nombres ligeramente distintos.
- [ ] Autor/institución está normalizado.
- [ ] Título está normalizado.
- [ ] Año está confirmado o marcado como desconocido.
- [ ] URL/DOI/identificador se conserva cuando existe.
- [ ] Fuentes web tienen fecha de consulta cuando corresponda.
- [ ] Fotografías tienen procedencia independiente.
- [ ] Los derechos/licencias de imágenes se revisarán en la fase visual.
- [ ] Las afirmaciones extraordinarias tienen una fuente proporcionalmente sólida.
- [ ] Las fuentes populares no se presentan como evidencia científica.

---

# 11. Regla de trazabilidad

Cada afirmación importante del expediente deberá poder responder:

> **¿De dónde salió esta información?**

La respuesta debe conducir a una fuente o, si proviene del manuscrito base y aún no se ha podido rastrear externamente, quedar marcada como:

> **ORIGEN: MANUSCRITO BASE — VERIFICACIÓN PENDIENTE**

Esta etiqueta es preferible a inventar una cita retrospectiva.

---

# 12. Criterio de cierre de v2.9

La v2.9 se considerará cerrada cuando:

1. las referencias de los 20 expedientes estén recopiladas;
2. los duplicados bibliográficos estén consolidados;
3. las fuentes tengan ID estable;
4. las fuentes críticas estén verificadas;
5. las afirmaciones principales tengan trazabilidad;
6. los vacíos R1/R2 estén registrados;
7. la bibliografía maestra pueda congelarse.

Hasta entonces:

**CANVA = BLOQUEADO.**
