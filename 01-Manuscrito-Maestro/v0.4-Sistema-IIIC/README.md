# v0.4 — Sistema IIIC y metodología editorial

## Contenido

Esta versión establece el lenguaje metodológico del Atlas:

- Sistema de clasificación IIIC de cinco niveles.
- Nivel I — Evidencia científica sólida.
- Nivel II — Evidencia física parcial.
- Nivel III — Evidencia documental.
- Nivel IV — Testimonios consistentes.
- Nivel V — Folclore y leyenda.
- Aplicación e interpretación de la clasificación.
- Cuatro pilares metodológicos: Documentación, Análisis, Comparación y Clasificación.
- Plantilla de ficha IIIC para los expedientes.

## Criterio editorial

El nivel IIIC describe el estado y tipo de evidencia disponible para un expediente; no constituye por sí mismo una sentencia definitiva sobre la existencia o inexistencia de una criatura.

- Gráfico de los cinco niveles.
- Diagrama de los cuatro pilares.
- Sello/indicador visual del nivel IIIC.
- Plantilla visual de ficha de expediente.
