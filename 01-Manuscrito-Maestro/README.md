# 01 — Manuscrito Maestro

Versiones oficiales del manuscrito editorial del **Atlas Criptozoológico — Volumen I: América**.

## Convención de versiones

- `v0.x` — desarrollo editorial.
- `v1.0` — manuscrito consolidado listo para maquetación/publicación.

Cada versión aprobada se conserva como entregable independiente para mantener trazabilidad.
