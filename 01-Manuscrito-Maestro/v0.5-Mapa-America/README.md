# v0.5 — Mapa general del continente americano

## Objetivo

El mapa funciona como puerta de entrada geográfica al Volumen I y sitúa al lector dentro del continente antes de comenzar los expedientes.

## Alcance respaldado por el manuscrito

El volumen está dedicado exclusivamente a América y la documentación base menciona los bosques boreales de Canadá, el Pacífico Norte, la Amazonía, los Andes, montañas, pantanos, desiertos y costas oceánicas como contextos geográficos o ambientales relevantes.

## Reglas cartográficas

- El mapa representa áreas asociadas a reportes, tradiciones o expedientes; no constituye evidencia de existencia.
- No se asignarán coordenadas precisas si el manuscrito no las proporciona.
- Las ubicaciones concretas se completarán al editar cada expediente.
- Se diferenciarán, cuando la documentación lo permita, origen del relato, zonas de reportes y zonas de investigación.
- La leyenda utilizará símbolos por categoría.

## Diseño propuesto

- Doble página horizontal.
- Mapa ilustrado de América.
- Leyenda de categorías.
- Marcadores regionales de expedientes.
- Nota metodológica vinculada al sistema IIIC.
- Espacios para completar ubicaciones precisas durante la edición de cada expediente.
